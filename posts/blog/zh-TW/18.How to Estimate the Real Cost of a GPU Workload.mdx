# 如何估算 GPU 工作負載的真實成本

只比較每小時單價不夠。應把啟動、下載、執行、失敗、持久化儲存與操作時間納入，換算成每個成功結果的成本。

## 計算方式

```text
總成本 = GPU 計費時間 + 儲存費 + 傳輸費 + 重試費 + 分攤的操作成本
單位成本 = 總成本 / 成功的工作、圖片、請求或 token 數
```

先定義「成功一件事」是什麼，再以相同 GPU、地區、幣別、計費單位與模型 revision 記錄。價格應以結帳頁與儀表板的實測為準，而不是只引用舊的公開價格。

## 容易漏掉的成本

- 模型下載與冷啟動時間
- 閒置但仍在計費的執行個體
- OOM、品質不符造成的重跑
- checkpoint、Snapshot 與 Datadrive
- 監控、更新與故障處理時間

比較候選方案時，請使用相同輸入、品質門檻與執行條件。便宜 GPU 若較慢、較常失敗或閒置很久，成功單價可能反而更高。
