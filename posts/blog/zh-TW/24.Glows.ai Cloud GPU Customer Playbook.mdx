# Glows.ai Cloud GPU 顧客實戰手冊

好的 GPU 決策不只是成功開機，而是為下一次實驗留下更安全、可說明的證據。本手冊把選型、成本、部署、效能、保存與擴展串成一條流程。

## 第一次實驗的流程

1. 從模型、context 與併發選擇 GPU 和量化，並實測 VRAM。
2. 定義包含費率、儲存、失敗與操作時間的成功單價。
3. 用相同品質門檻比較託管 API 與租用 GPU。
4. 部署具認證保護的 endpoint，測量 TTFT、p95、吞吐量與失敗率。
5. 保存資料、checkpoint、環境與復原程序，並測試中斷後能否續跑。
6. 只有在品質、成本、效能與可復原性達標時才擴展。

需要直接控制 GPU、模型、runtime 與持久化資產時，Glows.ai 很適合。若請求量很少或團隊沒有足夠的操作時間，託管 API 也可能更適合。重點是用當前實測與明確假設做決策。

發布前請核實價格、GPU 供應、地區、映像檔與命令，並從截圖與日誌移除所有秘密資訊。
